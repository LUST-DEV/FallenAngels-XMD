THE GRIMOIRE

Bot commands

The commands below are available after you link your device. The default prefix is ..

⌘

SYSTEM

Bot status

Check latency and view session statistics.

.pingalias: .p

☷

HELP

Command list

View available commands and their descriptions.

.menualiases: .help, .aide

✧

STICKERS

Create a sticker

Reply to an image or video. Video stickers are animated and limited to 3 seconds.

.stickersalias : .sticker, .s

✧

STICKERS TELEGRAM

Import a sticker pack

Send static or video stickers from a public Telegram pack. Owner only; requires TELEGRAM_BOT_TOKEN in .env. Animated TGS packs are not supported.

.tg https://t.me/addstickers/pack_namemaximum: 120 stickers

✧

INFORMATION

About

View information about the bot and its version.

.aboutalias: .botinfo

⚙

CUSTOMIZATION

Change the prefix

Choose a prefix made of 1 to 3 symbols. Owner only.

.setprefix !owner only

⌨

CUSTOMIZATION

Typing indicator

Show “typing…” while the bot prepares a response. Owner only.

.autotyping on.autotyping off to disable

❤️

AUTOMATION

React to status updates

Automatically react with a heart to status updates from your contacts. Owner only; the session must be connected.

.autoreact on.autoreact off · alias: .autoreacr

👁

AUTOMATION

Read private messages

Automatically mark received private messages as read without affecting groups. Owner only; the session must be connected.

.autoread on.autoread off to disable

✉

BROADCAST

Share a story

Share text or quoted media to the device’s groups. Owner only.

.gstories Hello!or reply to media · alias: .gstatut

♧

GROUPS / MODERATION

Manage members

Add or remove members, promote or demote admins, open or close the group, and manage warnings. Admin permissions are required; the bot must be an admin to moderate.

.add / .kick.promote · .demote · .open · .close · .warn · .warnings · .resetwarn · .kickall

📜

GROUPS / INFORMATION

Info & rules

View group information and admins, then update the group name, description, or rules.

.groupinfo.admins · .rules · .setrules <text> · .setname <name> · .setdesc <description>

📊

POLLS

Create a poll

Create a WhatsApp single-choice poll with at least two options.

.poll Question? | Yes | Noup to 12 options

✦

SOCIAL

Fun & profiles

Share a quote or fun fact, check compatibility, or view profile information.

.quote / .fact.ship @person · .profile [@person]

♫

MUSIC / MEDIA

TikTok & music

Download TikTok videos and find a source for a song’s lyrics.

.tiktok <link>.lyrics <title and artist> · opens an authorized lyrics source

🔗

GROUPS / MODERATION

Block links

Delete messages containing links in the group. Group admin permissions are required; the bot must be an admin to enable this and delete messages.

.antilink on.antilink off

📷

PROFILE

Profile pictures

Download a visible profile picture or change the bot’s picture by replying to an image. Changing it is owner only.

.getpp.getpp <number> · .setpp (reply to an image)

＠

GROUPS / MENTIONS

Notify the group

Mention all members, admins only, or the whole group without displaying tags.

.tagall.tagadmin · .hidetag <message>

✦

GROUPS / GREETINGS

Welcome & goodbye

Customizable default messages for members joining or leaving. Welcome messages include the profile picture, name, group, rules, date, and time. Enable them with .welcome on and .goodbye on.

.welcome on/off.setwelcome <message> · .goodbye on/off · .setgoodbye <message> · variables @name, @group, @rules, @date, @time
